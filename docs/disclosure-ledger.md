## Review checklist

- [ ] Search for secrets and environment files.
- [ ] Confirm examples, names, locators, and diagrams are synthetic and generic.
- [ ] Confirm the repository has a new Git history.
- [ ] Confirm no private repository was forked, mirrored, or made public.
- [ ] Confirm licensing and attribution are intentional.
- [ ] Record the reviewer and publication date in this file.
